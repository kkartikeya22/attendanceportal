This is an attendance portal application built with the MERN stack (MongoDB, Express, React, Node.js).

You can access the:- <br>
Backend on :- https://attendanceportal-2.onrender.com/ <br>

## Getting Started

These instructions will help you set up and run the project on your local machine for development and testing purposes.

## Prerequisites

Before you begin, ensure you have met the following requirements:

- You have installed [Node.js](https://nodejs.org/) and [npm](https://www.npmjs.com/).
- You have installed [MongoDB](https://www.mongodb.com/).

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/kkartikeya22/attendanceportal.git
   cd attendanceportal

## Running the Application

1. cd backend <br>
   npm run dev <br>
2. cd ../frontend <br>
   npm start <br>
